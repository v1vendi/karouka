Q&A

Isn't this just another Bootstrap?

It covers less on purpose: it styles elements rather than defining a component system.

Why so few components?

Anything HTML already provides doesn't need a new component.

What about accessibility?

Native elements carry their semantics with them, so there is less to get wrong.
